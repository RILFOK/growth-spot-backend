# Backend — установка и запуск

## Требования
Для локального запуска backend необходимы:
- Node.js
- npm
- PostgreSQL

Backend использует PostgreSQL как основную базу данных, поэтому перед запуском должен быть доступен рабочий экземпляр СУБД.

## Установка зависимостей
Для установки зависимостей выполните:

`npm install`

## Локальный запуск
Для локального запуска backend используйте:

`node index.js`

По умолчанию backend будет запущен на порту `3001`, если иное не указано в переменных окружения.

## Переменные окружения
Пример `.env` файла:

`DATABASE_URL=postgresql://user:password@localhost:5432/project1`

`JWT_SECRET=change_me`

`PORT=3001`

### Назначение переменных
- `DATABASE_URL` — строка подключения к PostgreSQL;
- `JWT_SECRET` — секрет для подписи JWT-токенов;
- `PORT` — порт запуска backend.

## Health-check
После запуска backend можно проверить его доступность командой:

`curl http://127.0.0.1:3001/api/health`

При успешном запуске сервер должен вернуть корректный ответ от endpoint'а `/api/health`.
