# Backend — обзор

Backend проекта `growth-spot.ru` представляет собой REST API на Node.js + Express с использованием PostgreSQL в качестве основной базы данных.

Он обслуживает административную и публичную части проекта, предоставляет данные для frontend и реализует серверную бизнес-логику.

## Основные возможности
Backend включает следующие основные возможности:
- авторизация по JWT;
- двухфакторная аутентификация (2FA);
- управление заявками;
- антиспам-защита;
- blocked IP и whitelist;
- управление пользователями и ролями;
- управление настройками сайта;
- health-check.

## Технологический стек
В backend используются:
- Node.js
- Express 5
- PostgreSQL
- `pg`
- JWT
- `bcryptjs`
- OTPAuth
- PM2

## Роль в проекте
Backend отвечает за:
- обработку API-запросов frontend;
- хранение и выдачу данных;
- серверную валидацию и проверки безопасности;
- управление доступом по ролям;
- взаимодействие с PostgreSQL;
- работу административных функций сайта.
