# Backend — пользователи

## Назначение
Backend предоставляет отдельный набор endpoint'ов для управления пользователями административной части проекта.

Через эти endpoint'ы реализуются операции просмотра пользователей, создания новых учётных записей, изменения ролей и смены паролей.

## Endpoint'ы
- `GET /api/users`
- `POST /api/users`
- `DELETE /api/users/:id`
- `PUT /api/users/:id/role`
- `PUT /api/users/me/password`
- `PUT /api/users/:id/password`

## Возможности
Пользовательский API поддерживает:
- просмотр пользователей;
- создание новых пользователей;
- удаление пользователей;
- изменение роли;
- смену своего пароля;
- смену пароля другого пользователя.

## Ограничения
Для пользовательского API действуют следующие ограничения:
- нельзя удалить самого себя;
- нельзя менять роль самому себе;
- moderator ограничен пользователями ниже своей роли;
- moderator не может назначать произвольные роли;
- для смены собственного пароля используется отдельный endpoint;
- смена роли и пароля увеличивает `token_version`, инвалидируя старые токены.

## Поведение при изменении роли и пароля
Backend использует механизм `token_version` для принудительного завершения старых сессий.

Если пользователю:
- изменили роль;
- сменили пароль;
- изменили пароль администратором или модератором,

старые JWT-токены становятся недействительными, и требуется повторная авторизация.
