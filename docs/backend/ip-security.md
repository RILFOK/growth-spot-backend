# Backend — IP безопасность

## Назначение
Backend использует отдельную логику IP-безопасности для защиты формы заявок от спама и повторяющихся подозрительных отправок.

В этой части системы используются два основных механизма:
- блокировка IP (`blocked_ips`);
- список исключений (`ip_whitelist`).

## Endpoint'ы
- `GET /api/blocked-ips`
- `POST /api/blocked-ips/:id/unblock`
- `GET /api/ip-info`
- `GET /api/ip-whitelist`
- `POST /api/ip-whitelist`
- `POST /api/ip-whitelist/:id/disable`

## Blocked IP
Механизм blocked IP используется для блокировки подозрительных IP-адресов при превышении лимита заявок.

Если IP не находится в whitelist и с него накапливается слишком много активных заявок, backend:
- добавляет IP в список заблокированных;
- помечает связанные новые заявки как спам;
- ограничивает дальнейшую отправку заявок.

## Разблокировка
При разблокировке:
- IP помечается как неактивный;
- новые спам-заявки этого IP удаляются.

Это позволяет очистить систему от автоматически помеченных подозрительных заявок после ручной разблокировки.

## Whitelist
Whitelist используется для IP-адресов, которые должны быть исключены из антиспам-ограничений.

Если IP добавлен в whitelist:
- на него не распространяется стандартный лимит антиспама;
- он не блокируется автоматически по обычному сценарию ограничения заявок.

Whitelist используется, например, для доверенных IP администратора или рабочих адресов.

## IP info
Endpoint `GET /api/ip-info` позволяет определить:
- текущий IP пользователя;
- находится ли он в whitelist;
- связанную whitelist-запись, если она существует.

## Особенность реализации
Endpoint `/api/ip-whitelist/:id/disable` по названию выглядит как отключение записи, но фактически удаляет её из таблицы.

Это означает, что текущая реализация использует не soft-disable, а физическое удаление записи из whitelist.

## Замечание
Логика IP-безопасности тесно связана с антиспам-механизмом заявок и административной панелью.

Подробности по условиям блокировки и лимитам заявок описаны в документе [Заявки и антиспам](./leads-and-antispam.md).
